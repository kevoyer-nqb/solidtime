# External Integrations

**Analysis Date:** 2026-02-10

## APIs & External Services

**Document Generation:**
- Gotenberg - PDF generation from HTML via Chromium
  - Used in: `app/Http/Controllers/Api/V1/TimeEntryController.php` - PDF export for time entries
  - SDK/Client: `gotenberg/gotenberg-php` 2.8
  - Config: `config/services.php` - `services.gotenberg.url` (env: `GOTENBERG_URL`)
  - Auth: Optional basic auth via `GOTENBERG_BASIC_AUTH_USERNAME` and `GOTENBERG_BASIC_AUTH_PASSWORD`
  - Endpoint: Expects URL like `http://gotenberg:3000` (configurable)

**OpenAPI Documentation:**
- Scramble - Auto-generates OpenAPI spec from Laravel API routes
  - Config: `config/scramble.php`
  - Endpoint: `/docs/api` - interactive Stoplight Elements UI
  - Output format: OpenAPI 3.0.1
  - Servers: Production, Staging, Local URLs defined in config

## Data Storage

**Databases:**
- PostgreSQL 15 - Primary database
  - Connection: `config/database.php` - `pgsql` connection
  - Client: Laravel Eloquent ORM (built-in)
  - Env vars: `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`
  - Test database: `pgsql_test` connection for test suite
  - Extensions: Laravel PostgreSQL Enhanced for advanced features

**File Storage:**
- S3-Compatible Object Storage
  - Client: League Flysystem AWS S3 v3
  - Default disk: Configured via `FILESYSTEM_DISK` env var
  - Endpoint: Configurable via `S3_ENDPOINT` (MinIO in local dev)
  - Config: `config/filesystems.php`
  - Env vars: `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_REGION`, `S3_BUCKET`, `S3_URL`, `S3_ENDPOINT`, `S3_USE_PATH_STYLE_ENDPOINT`
  - Local development: MinIO container at `http://storage.solidtime.test`

**Caching:**
- File-based caching (default, local development)
- Redis-compatible (if configured via env vars: `REDIS_HOST`, `REDIS_PASSWORD`, `REDIS_PORT`)
- Array caching in tests

## Authentication & Identity

**Web Authentication:**
- Laravel Jetstream 5.0 - User registration, password reset, two-factor auth
- Session-based authentication with Laravel's built-in Auth guard
- Session driver: Database-backed (configurable)
- Env var: `SESSION_DRIVER` - defaults to `database`, `array` in tests

**API Authentication:**
- Laravel Passport 13.0.5 - OAuth 2.0 server implementation
  - Personal Access Tokens for API clients
  - OAuth 2.0 authorization code flow for third-party integrations
  - Token models: Custom Passport models in `app/Models/Passport/`
    - `Token` - Access tokens
    - `RefreshToken` - Refresh tokens
    - `AuthCode` - Authorization codes
    - `Client` - OAuth clients
  - Configured in: `app/Providers/AuthServiceProvider.php`
  - Env vars: `PASSPORT_PERSONAL_ACCESS_CLIENT_ID`, `PASSPORT_PERSONAL_ACCESS_CLIENT_SECRET`
  - Scopes defined in AuthServiceProvider (exact scopes stored in code)
